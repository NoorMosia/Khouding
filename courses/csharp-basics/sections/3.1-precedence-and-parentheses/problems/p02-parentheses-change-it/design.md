# Problem 02, Parentheses change it (language-independent design)

**Sub-skill:** parentheses override the default order.
**Difficulty:** 1

## Statement (student-facing)
Print the value of the expression `(2 + 3) * 4`.

## I/O contract
- **Input:** none.
- **Output:** the value on its own line.

## Why it resists a trivial answer
Directly contrasts p01: same numbers, but the parentheses force `2 + 3` first, giving `20` instead of `14`.
The student must see that the parentheses change the result.
