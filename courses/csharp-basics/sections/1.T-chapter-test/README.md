# 1.T, Chapter 1 Test (region boss)

The Chapter 1 region boss. It combines everything from 1.1 to 1.5 into realistic multi-skill scenarios.
No new material is taught. Passing it lights the Chapter 1 region on the map.

## How it works
- **Pooled:** a single attempt draws **10** problems from the **20**-problem pool below. Passing **6**
  lights the region (~60%). A generous **24h** window; miss it or fall short and it simply does not light,
  a retry draws a fresh set. No lockouts, ever.
- **Non-memorizable:** the pool is bigger than the draw, and each scenario family has several value-varied
  variants, so memorizing one attempt's answers does not survive the next draw.
- Source of truth: `test.yaml`. Each pool problem is an ordinary problem folder under `pool/`; expecteds
  are generated by the oracle CLI from each `solution.cs`.

## Scope (same hard boundary as Chapter 1)
- **No input:** values are authored into each program; nothing is read from stdin (input is Chapter 2).
- **Arithmetic is `+ - *` only:** no `/`, no `%` (that depth is Chapter 3).
- Integrates: the program skeleton (1.1), output and escapes (1.2), `int`/`double`/`const`/arithmetic
  (1.3), `string`/`char`/`bool` (1.4), and legal, conventional, meaningful names (1.5).
