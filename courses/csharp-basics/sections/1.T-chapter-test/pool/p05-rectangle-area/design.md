# p05, Rectangle area, named (Family B, named constants)

**Integrates:** `const` + `*` (1.3) + naming (1.5) + output (1.2).

## Statement (student-facing)
A room is 8 wide and 5 high. Declare two well-named `const` variables for the width and height, then print
the area (width times height).

Print exactly:

```
40
```

## Why it belongs in the boss
Names the magic numbers as `const`s and computes with `*`. A light warm-up variant in the pool.
