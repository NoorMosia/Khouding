# p07, Weeks to days (Family B, named constants)

**Integrates:** `const` + `*` (1.3) + naming (1.5) + output (1.2).

## Statement (student-facing)
There are 7 days in a week. A span is 6 weeks. Use a well-named `const` for the 7, then print the number of
days.

Print exactly:

```
42
```

## Why it belongs in the boss
A light named-constant warm-up: name the 7, multiply by the weeks. A value-varied variant.
