# p08, Ticket sales (Family B, named constants)

**Integrates:** `const` + `+` and `*` (1.3) + naming (1.5) + multi-line output (1.2).

## Statement (student-facing)
Each ticket costs 15. The morning sold 20 tickets, the evening sold 35. Use a well-named `const` for the
price. Print the total number of tickets, then the total revenue.

Print exactly:

```
55
825
```

## Why it belongs in the boss
Combines `+` (summing the two sessions) and `*` (revenue) with a named price constant. A value-varied
variant.
