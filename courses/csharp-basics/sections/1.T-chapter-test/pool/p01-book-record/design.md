# p01, Book record (Family A, declare the fields)

**Integrates:** types (1.3/1.4) + naming (1.5) + multi-line output (1.2).

## Statement (student-facing)
Declare three well-named variables for a book: the title `Clean Code`, the author `Robert Martin`, and the
page count `464`. Print the title, author, and page count, each on its own line.

Print exactly:

```
Clean Code
Robert Martin
464
```

## Why it belongs in the boss
Pulls together choosing types (two `string`s and an `int`), naming them well, and printing a tidy block.
One of several value-varied declare-the-fields variants in the pool.
