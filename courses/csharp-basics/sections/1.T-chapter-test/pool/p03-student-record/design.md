# p03, Student record (Family A, declare the fields)

**Integrates:** types (1.3/1.4) + naming (1.5) + multi-line output (1.2).

## Statement (student-facing)
Declare three well-named variables for a student: the name `Lena`, the age `20`, and the grade `A` (a
single character). Print the name, age, and grade, each on its own line.

Print exactly:

```
Lena
20
A
```

## Why it belongs in the boss
A `string`, an `int`, and a `char` together, named well and printed to spec. A value-varied
declare-the-fields variant.
