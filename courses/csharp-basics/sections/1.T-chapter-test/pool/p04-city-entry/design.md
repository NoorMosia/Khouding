# p04, City entry (Family A, declare the fields)

**Integrates:** types incl. a light `bool` (1.3/1.4) + naming (1.5) + multi-line output (1.2).

## Statement (student-facing)
Declare three well-named variables for a city entry: the name `Riverton`, the population `85000`, and
whether it is a capital, `false`. Print the name, population, and capital flag, each on its own line.

Print exactly:

```
Riverton
85000
False
```

## Why it belongs in the boss
Brings the light `bool` into a declare-the-fields scenario. Note a `bool` prints with a capital first
letter (`False`), which is the kind of exact-output detail the boss rewards. A value-varied variant.
