# p02, Product card (Family A, declare the fields)

**Integrates:** types incl. `double` and `char` (1.3/1.4) + naming (1.5) + multi-line output (1.2).

## Statement (student-facing)
Declare three well-named variables for a product: the name `Hoodie`, the price `39.95`, and the size code
`L` (a single character). Print the name, price, and size code, each on its own line.

Print exactly:

```
Hoodie
39.95
L
```

## Why it belongs in the boss
Forces a real type choice across all three text/number kinds: a `string` name, a `double` price, and a
`char` size code. A value-varied declare-the-fields variant.
