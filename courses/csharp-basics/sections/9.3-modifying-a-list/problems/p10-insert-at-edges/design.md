# Problem 10, Insert at front and back (language-independent design)

**Sub-skill:** `Insert(0, x)` at the front; `Add(x)` at the back.
**Difficulty:** 3

## Statement (student-facing)
Read a count `n`, then `n` integers into a list. Then read a value to insert at the front (index 0) and a value to add at the back. Print all elements.
