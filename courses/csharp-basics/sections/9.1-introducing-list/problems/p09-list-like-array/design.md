# Problem 09, List and array, same output (language-independent design)

**Sub-skill:** zero-based indexing on a list, same syntax as an array.
**Difficulty:** 2

## Statement (student-facing)
Build a list containing 10, 20, 30. Print each element using its index.

## I/O contract
- **Input:** none.
- **Output:** three lines: 10, 20, 30.

## Why it resists a trivial answer
Structural: the output is fixed, but the skill is writing the Add calls and using `list[0]`, `list[1]`, `list[2]`.
