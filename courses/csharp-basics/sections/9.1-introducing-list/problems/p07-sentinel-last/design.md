# Problem 07, Sentinel build last value (language-independent design)

**Sub-skill:** sentinel build + `list[list.Count - 1]`.
**Difficulty:** 2

## Statement (student-facing)
Read integers one per line until "stop". Add each to a list. Print the last integer added. The input always has at least one integer before "stop".

## I/O contract
- **Input:** one or more integers, then "stop".
- **Output:** one line, `list[list.Count - 1]`.
