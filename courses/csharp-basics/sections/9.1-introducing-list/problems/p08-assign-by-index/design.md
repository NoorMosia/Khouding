# Problem 08, Assign by index (language-independent design)

**Sub-skill:** `list[i] = value` to overwrite an existing slot.
**Difficulty:** 2

## Statement (student-facing)
Read three integers into a list. Then read a new value and assign it to index 1. Print the updated `list[1]`.

## I/O contract
- **Input:** three integers (for the initial list), then one more value.
- **Output:** one line, the new `list[1]`.
