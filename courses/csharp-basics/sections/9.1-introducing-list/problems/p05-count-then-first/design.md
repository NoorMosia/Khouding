# Problem 05, Count then first (language-independent design)

**Sub-skill:** `list.Count` and `list[0]` together.
**Difficulty:** 2

## Statement (student-facing)
Read a count `n` (at least 1), then `n` integers into a list. Print `list.Count`, then `list[0]`, each on its own line.

## I/O contract
- **Input:** `n` (>= 1), then `n` values.
- **Output:** two lines: Count then first element.
