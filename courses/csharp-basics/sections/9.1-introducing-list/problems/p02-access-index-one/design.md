# Problem 02, Access index 1 (language-independent design)

**Sub-skill:** `list[i]` indexing.
**Difficulty:** 1

## Statement (student-facing)
Read three integers into a list. Print the element at index 1.

## I/O contract
- **Input:** three lines, one integer each.
- **Output:** one line, `list[1]`.

## Why it resists a trivial answer
The middle element varies. Cases vary it including negatives and zero.

## Note
Zero-based: index 1 is the second element.
