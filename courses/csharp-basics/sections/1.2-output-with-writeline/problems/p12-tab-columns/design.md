# Problem 12, Tab columns (language-independent design)

**Sub-skill:** the `\t` escape for a tab, used to separate columns.
**Difficulty:** 2

## Statement (student-facing)
Print two columns on one line, separated by a tab:

```
Name	Ada
```

Use the `\t` escape between the two words. It must be a tab, not spaces.

## I/O contract
- **Input:** none.
- **Output:** `Name`, a tab character, `Ada`, then a newline.

## The idea
`\t` is a single tab character. It is not the same as spaces, even if it can look similar on screen.

## Why it resists a trivial answer
Grading is byte-exact. Spaces between the words would not match the tab in the expected output. The student
must use `\t`. (The expected output is generated by running the reference solution, so it carries a real
tab, no human types the invisible character.)
