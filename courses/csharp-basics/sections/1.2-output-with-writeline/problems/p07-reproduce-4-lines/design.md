# Problem 07, Reproduce a 4-line block (language-independent design)

**Sub-skill:** precision across a longer block.
**Difficulty:** 2

## Statement (student-facing)
Print exactly this:

```
Order summary
Coffee
Muffin
Thank you!
```

## I/O contract
- **Input:** none.
- **Output:** the four lines above, in order.

## Why it resists a trivial answer
A longer exact-reproduction rep, including the `!`. Each line must match. This is the last pure
line-structure problem before escape sequences arrive.
