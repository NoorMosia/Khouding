# Problem 01, Print one line (language-independent design)

**Sub-skill:** baseline `WriteLine`, print one line.
**Difficulty:** 1

## Statement (student-facing)
Print exactly this:

```
Welcome to the console.
```

## I/O contract
- **Input:** none.
- **Output:** the single line above.

## Why it resists a trivial answer
Target text is unique to this problem, so a solution cannot be copied from another. The exact text must
match byte for byte.
