# Problem 02, Print three lines (language-independent design)

**Sub-skill:** line structure, one `WriteLine` per line.
**Difficulty:** 1

## Statement (student-facing)
Print exactly this:

```
Line one.
Line two.
Line three.
```

## I/O contract
- **Input:** none.
- **Output:** the three lines above, each on its own line.

## Why it resists a trivial answer
Each line is distinct and the order is fixed; a single literal cannot match. Byte-exact.
