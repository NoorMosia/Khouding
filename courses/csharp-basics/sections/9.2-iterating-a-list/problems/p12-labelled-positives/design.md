# Problem 12, Labelled positives (language-independent design)

**Sub-skill:** filter + running 1-based label over printed items (capstone).
**Difficulty:** 3

## Statement (student-facing)
Read a count `n`, then `n` integers into a list. Print only the elements greater than 0, labelled with their
position among the printed elements: `label: value`. The label counts only the elements that are printed.
