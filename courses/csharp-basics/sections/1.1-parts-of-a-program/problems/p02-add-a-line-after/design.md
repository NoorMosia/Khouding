# Problem 02, Add a line after (language-independent design)

**Sub-skill:** statements run top to bottom; a line added after prints after.
**Difficulty:** 1

## Statement (student-facing)
One line is already printed. Add one more line below it so the program prints exactly:

```
Good morning.
Have a great day.
```

## I/O contract
- **Input:** none.
- **Output:** two lines, `Good morning.` then `Have a great day.`

## Why it resists a trivial answer
Order matters: the new statement must come after the existing one to produce the target order. The target
text is unique to this problem.
