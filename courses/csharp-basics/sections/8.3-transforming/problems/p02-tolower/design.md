# Problem 02, Lower case (language-independent design)

**Sub-skill:** `ToLower()` returns a new string.
**Difficulty:** 1

## Statement (student-facing)
Read a line of text. Print it lower-cased.

## I/O contract
- **Input:** one line.
- **Output:** one line, all characters lower-cased.

## Why it resists a trivial answer
Cases vary mixed case, already-lower, and a single char, so a fixed answer fails.

## Note
Use the returned value.
