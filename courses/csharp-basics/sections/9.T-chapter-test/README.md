# 9.T, Chapter 9 Test (region boss)

The Chapter 9 region boss. Combines 9.1-9.5 (resting on Chapters 1-8) into realistic list scenarios.
No new material. Passing it lights the Chapter 9 region on the map.

## How it works
- **Pooled:** a single attempt draws **10** problems from the **20**-problem pool. Passing **6** lights the
  region (~60%). A generous **24h** window; miss it or fall short and it simply does not light; a retry draws
  a fresh set. No lockouts.
- Source of truth: `test.yaml`. Each pool problem is an ordinary problem folder under `pool/`; expecteds are
  generated by the oracle CLI from each `solution.cs` (including `asset_files` for family F).

## Scope
- **Input via stdin** (count-then-values or sentinel). Family F reads a provided read-only file (Flavor A).
- Full list toolkit: create/Add/Count/index (9.1), iteration (9.2), modification (9.3), operations (9.4),
  methods (9.5), on top of Chapters 1-8.
- No LINQ, no `Dictionary`, no `List.Sort()`.
