# Problem 08, A bool flag (language-independent design)

**Sub-skill:** declare a `bool` (a type with two possible values) and print it.
**Difficulty:** 1

## Statement (student-facing)
Declare a `bool` variable named `isOpen` set to `true`, and print it.

Print exactly:

```
True
```

## I/O contract
- **Input:** none.
- **Output:** `True` (note the capital T: that is how C# prints a `bool`).

## Why this problem
A light first touch of `bool`: a type that holds one of two values, `true` or `false`. No comparisons or
logic yet (that is a later chapter). The point is just declaring one and seeing how it prints.
