# Problem 09, Reprint an initial (language-independent design)

**Sub-skill:** a second `char` rep; a `char` is exactly one character.
**Difficulty:** 1

## Statement (student-facing)
Read a person's initial (a single character) into a `char`, and print it on its own line.

## I/O contract
- **Input:** one line, exactly one character.
- **Output:** that character.

## Why it resists a trivial answer
Varied single characters (upper, lower, a symbol) mean no printed literal passes. Reinforces that a `char`
holds exactly one character, read into a variable and printed.
