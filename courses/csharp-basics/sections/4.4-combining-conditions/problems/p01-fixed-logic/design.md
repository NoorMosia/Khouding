# Problem 01, Fixed logic (language-independent design)

**Sub-skill:** the three operators on bare booleans.
**Difficulty:** 1

## Statement (student-facing)
Print exactly this:
```
False
True
False
```
The three lines are the results of `true && false`, `true || false`, and `!true`, in that order.

## I/O contract
- **Input:** none.
- **Output:** three lines, each `True` or `False`.

## Why it resists a trivial answer
This is the warm-up rep, so the family escalates immediately after. Later problems read input, so a copied
literal from here cannot carry over.
