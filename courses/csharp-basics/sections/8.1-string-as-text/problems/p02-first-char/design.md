# Problem 02, First character (language-independent design)

**Sub-skill:** `s[0]`.
**Difficulty:** 1

## Statement (student-facing)
Read a line of text. Print its first character.

## I/O contract
- **Input:** one non-empty line.
- **Output:** one line, the first character.

## Why it resists a trivial answer
The first character depends on the input. Cases vary it, so a fixed letter fails.

## Note
`s[0]` is a `char`; printing it prints the single character.
