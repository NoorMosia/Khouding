# Problem 02, First line (language-independent design)

**Sub-skill:** open with `using`, call `ReadLine()` once.
**Difficulty:** 2

## Statement (student-facing)
The file `data.txt` is provided. Print its first line.

## I/O contract
- **Input:** none.
- **Output:** one line, the first line of `data.txt`.

## Note
One `ReadLine()` call is enough; no loop needed. The `using` block closes the file.
