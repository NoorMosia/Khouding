# Problem 05, Upper-case each line (language-independent design)

**Sub-skill:** read loop + `ToUpper()` per line (ties 8.3).
**Difficulty:** 2

## Statement (student-facing)
The file `data.txt` is provided. Print every line upper-cased.

## I/O contract
- **Input:** none.
- **Output:** each line of `data.txt` in upper case.

## Note
`Console.WriteLine(line.ToUpper())` uses the return value of `ToUpper`.
