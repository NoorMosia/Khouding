# Pool p14, Build a full name (family D, build a string)

**Integrates:** 2.1 (read), 2.4 (join with `+` into a stored string).
**Difficulty:** 2

## Statement (student-facing)
Read a first name and a last name, each prompted on its own line. Build a single `string` variable `fullName`
that joins the first name, a space, and the last name. Print `fullName`.

## I/O contract
- **Input:** two lines: a first name, then a last name.
- **Output:** the two prompts, then the full name on its own line.

## Why it resists a trivial answer
The names vary; the task is to build and store the joined string, then print the variable, the dual role of
`+` from 2.4.
