# 2.T, Chapter 2 Test (region boss)

The Chapter 2 region boss. It combines everything from 2.1 to 2.5 (resting on Chapter 1) into realistic
input-to-output scenarios. No new material is taught. Passing it lights the Chapter 2 region on the map.

## How it works
- **Pooled:** a single attempt draws **10** problems from the **20**-problem pool below. Passing **6**
  lights the region (~60%). A generous **24h** window; miss it or fall short and it simply does not light,
  a retry draws a fresh set. No lockouts, ever.
- **Non-memorizable, from both sides:** the pool is bigger than the draw, AND (unlike the Chapter 1 boss)
  these problems take stdin, so each pool problem carries several value-varied input cases. Memorizing one
  attempt's answers does not survive the next draw, and a hardcoded literal cannot pass a problem's own
  varied cases.
- Source of truth: `test.yaml`. Each pool problem is an ordinary problem folder under `pool/`; expecteds are
  generated by the oracle CLI from each `solution.cs`.

## Scope (same boundary as Chapter 2)
- **Input is used:** values come in via stdin. Prompts are printed on their own line, and the prompt text is
  part of the graded output.
- **Arithmetic is `+ - *` only:** no `/`, no `%` (that is Chapter 3).
- **Money is a label plus `:F2`**, no currency symbol, so output is deterministic under invariant culture.
- Integrates: reading input (2.1), parsing and computing (2.2), interpolation (2.3), joining strings with
  `+` (2.4), and formatting numbers with `:F2` (2.5), on top of Chapter 1's types, naming, and output.
