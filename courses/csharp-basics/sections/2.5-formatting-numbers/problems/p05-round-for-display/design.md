# Problem 05, Round for display (language-independent design)

**Sub-skill:** `:F2` rounds the display; the stored value is unchanged (display vs stored).
**Difficulty:** 2

## Statement (student-facing)
Prompt `Enter a value:` on its own line and read it as a decimal number. The value may have more than two
decimal places. Print it to two decimal places with `:F2`.

## I/O contract
- **Input:** one line holding a decimal number with up to three decimal places.
- **Output:** the prompt, then the value rounded to two decimal places on its own line.

## Why it resists a trivial answer
Each input has three decimals and must be shown with two, so the format must round the display. A raw print
would show all three digits. The point is that `:F2` changes only how the number looks, not the value held in
the variable.

## Authoring note
Expecteds are generated by the oracle under invariant culture. Cases avoid exact-half ties (no value whose
rounding depends on floating-point storage quirks); each rounds unambiguously, verified via the CLI.
