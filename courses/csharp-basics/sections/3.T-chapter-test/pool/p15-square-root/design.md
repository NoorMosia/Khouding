# Pool p15, Square root (family D, updating & Math)

**Integrates:** 3.5 (`Math.Sqrt`), 2.1/2.2.
**Difficulty:** 1

## Statement (student-facing)
Read a number. Print its square root using `Math.Sqrt`.

## I/O contract
- **Input:** one line, a number.
- **Output:** the prompt, then the square root.

## Why it resists a trivial answer
Perfect-square inputs give clean whole results (`16` to `4`), varied so a copied literal fails.
