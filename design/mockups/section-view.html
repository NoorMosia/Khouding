Section 1.3

Number variables: int and double

Declare, initialise, and reassign numbers, and choose int vs double.

A variable is a labelled jar on a shelf. You put a value in the jar, you write a name on the label, and whenever you say the name you get whatever is currently in the jar. You can pour a new value in later; the old one is gone.

Two kinds of number

C# makes you say what kind of number a jar holds. Use int for whole counts, and double when the value can be fractional.

A count of students is an int; you never have 3.5 students. A height in metres is a double, because 1.72 is perfectly normal.
