Section 1.3

Number variables: int and double

Store numbers, choose the right type, and combine them.

Part 1What a variable is

A variable is a named place that holds a value. You give it a name, you put a value in it, and whenever you use the name you get whatever value it currently holds. You can give it a new value later; the old one is replaced.

This section works with variables that hold numbers.

Part 2Two kinds of number

C# makes you say what kind of number a variable holds. Two you will use constantly:

  • int is a whole number. No fractional part. Ages, counts. 0, 42, -7.
  • double can have a decimal part. Prices, measurements, averages. 3.14, 4.99, -0.5.

The decision you make every time: can this value ever need a fractional part? If yes, double. If it is always a whole thing you count, int.

What a "type" really is. An int is exact but holds whole numbers only. A double reaches a vast range but is approximate: it trades perfect accuracy for that range, so you will occasionally see 0.1 + 0.2 print as 0.30000000000000004. That is normal for a double, not a bug. File it away.

Part 3Declaring and initialising

Write the type, then the name, then a starting value.

1 2 3 4
int age = 19; double price = 4.99; Console.WriteLine(age); Console.WriteLine(price);
output
19 4.99

Read int age = 19; as "make an int called age, and put 19 in it." The = does not mean "equals". It means put this value into this variable. Say it as "age gets 19", never "age equals 19". That misreading is the most common beginner trap.

Part 4Reassigning

Give an existing variable a new value. Do not repeat the type; the variable already exists.

1 2 3
int score = 10; score = 25; Console.WriteLine(score);
output
25

Only the first mention needs the type. After that, just the name. The old 10 is gone.

Part 5A value that never changes: const

Some values should never change once set. Mark one const and C# stops it being reassigned by mistake. It also gives a bare number a name.

1 2 3
const int DaysInWeek = 7; int weeks = 3; Console.WriteLine(weeks * DaysInWeek);
output
21

weeks * 7 works, but weeks * DaysInWeek says what the 7 means. Named constants make code read for itself.

Part 6Using numbers together

Combine numbers in variables with +, -, and *.

1 2 3 4
int apples = 3; int oranges = 5; int total = apples + oranges; Console.WriteLine(total);
output
8

That is the whole arithmetic toolkit for now: add, subtract, multiply. (Division has a surprise in it, so it waits for the next chapter.)

Part 7When it does not compile

If you put a decimal into an int:

Program.cs(7,21): error CS0266: Cannot implicitly convert type 'double' to 'int'. An explicit conversion exists (are you missing a cast?)

int holds whole numbers only, so int price = 4.99; is rejected. If the value can be fractional, make the variable a double.

If you use a variable before putting anything in it:

Program.cs(8,27): error CS0165: Use of unassigned local variable 'total'

You declared the variable but never gave it a value. Assign one before you read from it.

Part 8What you'll practise

Declaring ints and doubles, choosing the right type, reassigning, naming fixed values with const, and combining numbers with +, -, and *. Fifteen reps. Wax on, wax off.
